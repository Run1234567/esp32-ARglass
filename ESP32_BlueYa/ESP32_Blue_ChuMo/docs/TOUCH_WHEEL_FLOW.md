# 电容式触摸轮盘 - 完整流程文档

## 从上电到检测到触摸

---

## 第 0 步：系统时钟配置

```
HSE 晶振 25MHz
    ↓
PLL 分频: 25MHz / 15 = 1.667MHz
    ↓
PLL 倍频: 1.667MHz × 96 = 160MHz
    ↓
PLL 分频: 160MHz / 2 = 80MHz → SYSCLK
    ↓
AHB 不分频 → HCLK = 80MHz
APB1 分频 /2 → PCLK1 = 40MHz（但定时器自动×2 → 80MHz）
APB2 不分频 → PCLK2 = 80MHz
```

**结论：TIM2、TIM3 挂在 APB1 上，定时器时钟 = 80MHz。**

---

## 第 1 步：外设初始化

CubeMX 生成的代码依次初始化 GPIO、DMA、ADC、TIM1~TIM4、USART1/2/6。

### 定时器关键配置

```c
// TIM2 和 TIM3 完全相同的配置
htim3.Init.Prescaler = 8 - 1;    // 分频系数 = 8
htim3.Init.Period = 65535;        // 自动重装载值（最大）
```

```
定时器时钟 80MHz
    ↓
Prescaler = 8（分频）
    ↓
计数频率 = 80MHz / 8 = 10MHz
    ↓
1 个计数 = 0.1μs
最大计数 = 65535 → 最大可测时间 = 65535 × 0.1μs = 6.5535ms
```

### 输入捕获配置

```c
sConfigIC.ICPolarity  = TIM_INPUTCHANNELPOLARITY_RISING;  // 上升沿触发
sConfigIC.ICSelection = TIM_ICSELECTION_DIRECTTI;          // 直连输入
sConfigIC.ICPrescaler = TIM_ICPSC_DIV1;                    // 捕获不分频
sConfigIC.ICFilter    = 0;                                  // 无滤波
```

**含义：引脚上每出现一次上升沿，就把当前计数值锁存到 CCR 寄存器，并触发中断。**

---

## 第 2 步：启动定时器 + 校准

```c
HAL_TIM_Base_Start_IT(&htim2);  // 启动 TIM2 基础中断
HAL_TIM_Base_Start_IT(&htim3);  // 启动 TIM3 基础中断
HAL_TIM_Base_Start_IT(&htim4);  // 启动 TIM4（LED 心跳闪烁用）

TPAD_Init();  // ← 触摸校准
```

### TPAD_Init() 做了什么（cap_touch.c:236-287）

```
┌──────────────────────────────────────────────────────────────┐
│  校准过程（此时没有手指触摸）                                    │
│                                                              │
│  循环 10 次:                                                  │
│    每次调用 TPAD_Get_Val() 测量 5 个通道的充电时间              │
│    结果存入 TIM_CAP_VALUE_BUFF[0~49]（每通道 10 个样本）        │
│                                                              │
│  对每个通道:                                                  │
│    取 10 个样本中下标 2~7 的 6 个值（去掉了最大2个和最小2个）     │
│    求平均 → 存入 TIM_CAP_VALUE_DEFAULT[0~4]                   │
│                                                              │
│  串口打印: "default1:150, default2:148, default3:152, ..."    │
└──────────────────────────────────────────────────────────────┘
```

校准完后，LED 灯做一些动画（流水灯、全亮等），然后进入主循环。

---

## 第 3 步：主循环

```c
while (1) {
    TPAD_Scan(1);  // 连按模式，持续扫描
    // 串口打印哪个方向被按下了
}
```

---

## 第 4 步：TPAD_Scan(1) 内部流程（cap_touch.c:379-466）

这是核心，每轮循环都执行一遍：

```
TPAD_Scan(1) ── mode=1（连按模式）
    │
    ├─ ① 设置采样次数 = 6（连按模式比单按模式多采几次，更可靠）
    │
    ├─ ② 清零 Is_pressed[5]（本次扫描的按下标志）
    │
    ├─ ③ 调用 TPAD_Get_MaxVal(6) ── 采样 6 次，每个通道取最大值
    │       │
    │       └─ 循环 6 次:
    │             调用 TPAD_Get_Val() ── 测量 5 个通道
    │             │
    │             ├─ TPAD_Reset() ── 放电 + 切换输入捕获
    │             │
    │             └─ 等待 5 个中断标志，读取 5 个 CCR 值
    │
    ├─ ④ 判断 4 个外环通道是否按下
    │
    ├─ ⑤ 判断中心通道是否按下
    │
    ├─ ⑥ 更新松开计数器
    │
    └─ ⑦ 根据按下状态驱动 LED
```

### 第 4a 步：TPAD_Get_Val() 详细流程（cap_touch.c:174-193）

这是单次测量 5 个通道的过程：

```
TPAD_Get_Val(&v1, &v2, &v3, &v4, &v5)
    │
    └─ TPAD_Reset()  ← 核心函数
        │
        │  ┌─────────────────────────────────────────────────────┐
        │  │ 阶段 A: 强制放电                                     │
        │  │                                                     │
        │  │ PA6,PA7,PB0,PB1,PB10 全部配置为推挽输出，输出 LOW     │
        │  │ → 5 个焊盘电容全部通过 GPIO 强制放电到 0V              │
        │  │ → 等待约 1ms 确保放电完成                              │
        │  └─────────────────────────────────────────────────────┘
        │
        │  ┌─────────────────────────────────────────────────────┐
        │  │ 阶段 B: 切换为输入捕获 + 启动定时器                    │
        │  │                                                     │
        │  │ 1. 清零 5 个中断标志位                                │
        │  │ 2. 清零 TIM2、TIM3 的计数器                           │
        │  │ 3. 启动 5 个通道的输入捕获中断                         │
        │  │ 4. 把 5 个 GPIO 从推挽输出切换为定时器复用功能          │
        │  │                                                     │
        │  │ → 切换瞬间，电容开始通过浮空输入的微弱上拉充电          │
        │  │ → 定时器开始从 0 计数                                  │
        │  └─────────────────────────────────────────────────────┘
        │
    ┌───┴────────────────────────────────────────────────────────┐
    │ 阶段 C: 等待充电完成（中断方式）                               │
    │                                                            │
    │ while(T3_CH1_IC_IT_FLAG == 0) HAL_Delay(0);  // 等 RIGHT   │
    │   → PA6 电压上升到阈值 → TIM3 CH1 捕获 → 中断 → FLAG=1      │
    │   → 读取 CCR1 = 充电时间（比如 150）                         │
    │                                                            │
    │ while(T3_CH2_IC_IT_FLAG == 0) HAL_Delay(0);  // 等 UP      │
    │   → PA7 捕获 → CCR2 = 148                                   │
    │                                                            │
    │ while(T3_CH3_IC_IT_FLAG == 0) HAL_Delay(0);  // 等 DOWN    │
    │   → PB0 捕获 → CCR3 = 152                                   │
    │                                                            │
    │ while(T3_CH4_IC_IT_FLAG == 0) HAL_Delay(0);  // 等 LEFT    │
    │   → PB1 捕获 → CCR4 = 149                                   │
    │                                                            │
    │ while(T2_CH3_IC_IT_FLAG == 0) HAL_Delay(0);  // 等 CENTER  │
    │   → PB10 捕获 → CCR5 = 151                                  │
    └────────────────────────────────────────────────────────────┘
```

### 第 4b 步：判断是否按下（cap_touch.c:399-421）

对每个通道 i（0~3 外环，4 中心）:

```
采样 6 次取最大值 → TIM_CAP_VALUE_NOW[i]

判断条件:
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   DEFAULT[i] + GATE < NOW[i] < 10 × DEFAULT[i]             │
│   ↑                       ↑                    ↑            │
│   下限                    当前值               上限           │
│                                                              │
│   下限: 充电时间必须比基准多出门限值才算"有触摸"               │
│          外环 GATE=20 (2μs), 中心 GATE=10 (1μs)             │
│                                                              │
│   上限: 防止异常大值误判（超过基准 10 倍视为无效）              │
│                                                              │
└──────────────────────────────────────────────────────────────┘

如果条件满足:
  且 release_cnt[i] == 3（之前已经松开过 3 次扫描）
    → Is_pressed[i] = 1（标记有效按下）
  release_cnt[i] = 0（清零松开计数器）

如果条件不满足（没按下）:
  release_cnt[i]++（松开计数器递增，最多到 3）
```

### 第 4c 步：驱动 LED（cap_touch.c:432-464）

```
如果任何 Is_pressed 为 1:
    │
    ├─ 如果按下的是中心 (Is_pressed[4]):
    │     LED 全部点亮（平滑/快速动画）
    │
    └─ 如果按下的是外环:
           │
           ├─ 计算每个通道的 delta = NOW - DEFAULT
           │
           ├─ RIGHT_DELTA, UP_DELTA, DOWN_DELTA, LEFT_DELTA
           │
           ├─ 计算角度:
           │   right_left = RIGHT_DELTA - LEFT_DELTA
           │   down_up    = DOWN_DELTA - UP_DELTA
           │   angle = atan(right_left / down_up) → 修正到 0°~360°
           │
           └─ 点亮对应角度的那颗 LED（32颗，每颗11.25°）

如果没有任何按下:
    LED 全部熄灭
```

## 关键数值举例

假设校准时基准值 DEFAULT[0] = 150（RIGHT 通道）：

| 场景 | 充电时间 | delta | 判断 |
|------|---------|-------|------|
| 没人碰 | 148~152 | -2 ~ +2 | < 门限 20，不触发 |
| 手指轻触 | 165 | +15 | < 门限 20，不触发 |
| 手指按实 | 175 | +25 | > 门限 20，触发 |
| 手指用力按 | 200 | +50 | > 门限 20，触发 |
| 异常/短路 | > 1500 | > 10×基准 | 上限过滤，不触发 |

## ESP32-S3 移植对照

| STM32 原版 | ESP32-S3 移植版 | 说明 |
|------------|----------------|------|
| TIM 输入捕获中断 | ADC 轮询采样 | ESP32 无输入捕获，改用 ADC 读电压 |
| 浮空上拉充电 | 1MΩ 外部电阻充电 | 外部 RC 定时更可控 |
| CCR 计数值 | ADC 原始值 | 充电时间越长，电压越高，ADC 值越大 |
| DEFAULT + GATE | Touch_Vref - Touch_Diff | 方向相反：原版测充电时间，新版测电压 |
| GATE = 20 | TOUCH_GATE = 30 | ADC 精度不同于定时器，需独立调参 |
